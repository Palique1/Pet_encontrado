# 🐾 Pet Encontrado - Aplicativo Mobile

Aplicativo web mobile para busca, cadastro e resgate colaborativo de animais de estimação perdidos e encontrados na comunidade.

---

## 🎨 Paleta de Cores (Natural Tones)

- **Fundo / Canvas**: `#FDFBF7` (Off-white / Bege suave)
- **Destaque Principal**: `#7A9D8C` (Verde Sálvia)
- **Destaque Secundário**: `#E6B89C` (Terracota / Areia suave)
- **Textos e Ícones**: `#3D3D3D` (Carvão) e `#5C5C5C`
- **Bordas e Divisores**: `#EAE7E2` e `#F2EDE4`

---

## 🚀 Funcionalidades

- **Tela Inicial (Explorar)**:
  - Feed com filtros por espécie (Todos, Cães, Gatos, Outros) e status (Perdidos / Encontrados).
  - Cards detalhados com foto, raça, localização, data e recompensa.
  - Indicador de modo de visualização (Mobile Frame e Tela Cheia).
- **Detalhes do Pet**:
  - Informações completas (Porte, Raça, Cor, Idade, Características especiais).
  - Mini mapa ilustrado com raio de busca.
  - Contato direto com o tutor via WhatsApp, Ligação e E-mail.
  - Gerador de Cartaz de Busca ("Procura-se") pronto para salvar/imprimir.
- **Mapa de Busca**:
  - Visualização gráfica com ajuste de raio em quilômetros (5km, 10km, 20km, 50km).
  - Marcadores interativos de pets na região.
- **Notificações**:
  - Alertas de avistamentos recentes e avisos de segurança para tutores.
- **Cadastro de Pets**:
  - Modal com formulário completo para publicação de anúncios de animais perdidos e encontrados.
- **Alerta de Avistamento**:
  - Envio instantâneo de localização e fotos para tutores ao avistar um animal.

## 💻 Como Rodar o Projeto Localmente (Desenvolvimento)

1. Clone ou baixe o repositório:
```bash
git clone <URL_DO_SEU_REPOSITORIO>
cd pet-encontrado
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
```
http://localhost:3000
```
